## Sobre mim

Desenvolvedor Full Stack com mais de 3 anos de experiência em desenvolvimento e manutenção de software em ambiente de produto SaaS. Atuo na **Braip** — uma das maiores plataformas de afiliados do Brasil — onde participo diretamente do desenvolvimento, debug em produção e colaboração com times de produto e tecnologia.

Trabalho com aplicações web e mobile utilizando TypeScript, Vue.js, Nuxt.js e React Native no front; Node.js e PHP no back; PostgreSQL, MySQL e MongoDB no banco de dados; e Docker para containerização.

Tenho interesse em segurança da informação aplicada ao desenvolvimento (DevSecOps) e boas práticas OWASP.

## Projetos em destaque

### [store-api-wigo](https://github.com/wigodz/store-api-wigo)
API REST para e-commerce construída com Node.js, TypeScript, PostgreSQL e Prisma ORM — containerizada com Docker.  
Inclui autenticação JWT com controle de roles, validação com Zod, transações atômicas para pedidos com controle de estoque, rate limiting e tratamento centralizado de erros.

`Node.js` `TypeScript` `PostgreSQL` `Prisma` `Docker` `JWT` `Zod`

---

### [estudo-arq](https://github.com/wigodz/estudo-arq)
Estudo prático de arquitetura de software com PHP, Laravel e Blade — explorando separação de responsabilidades, padrões MVC e organização em camadas aplicados a um sistema web real.

`PHP` `Laravel` `Blade` `HTML` `CSS`
