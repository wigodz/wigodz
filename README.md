## Sobre mim

Desenvolvedor Full Stack com mais de 3 anos de experiência em desenvolvimento e manutenção de software em ambiente de produto SaaS. Atuo na **Braip** — uma das maiores plataformas de afiliados do Brasil — onde desenvolvo funcionalidades, faço debug em produção e colaboro com times de produto e tecnologia.

Trabalho com aplicações web e mobile usando TypeScript, Vue.js, Nuxt.js e React Native no front; Node.js e PHP no back; PostgreSQL, MySQL e MongoDB no banco; e Docker para containerização. Tenho interesse em segurança da informação aplicada ao desenvolvimento (DevSecOps/OWASP).

## Projetos em destaque

### [store-api-wigo](https://github.com/wigodz/store-api-wigo)
API REST para e-commerce — Node.js, TypeScript, PostgreSQL e Prisma ORM, containerizada com Docker.
JWT com controle de roles, validação com Zod, transações atômicas para pedidos com controle de estoque, rate limiting e error handling centralizado.

`Node.js` `TypeScript` `PostgreSQL` `Prisma` `Docker` `JWT` `Zod`
